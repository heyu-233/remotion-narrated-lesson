# Code walkthrough rules

Use static syntax highlighting and declarative code windows. Bind each narration anchor to one line, or a very small contiguous range, through the episode semantic timeline. Do not use Monaco command scrolling, CSS transitions, or a chapter-wide highlight.

Raw transcription is alignment evidence. Reviewed narration text and caption references belong in `episodes/<id>/timeline.json`, which is the runtime timing authority. Outside a cue, keep the prior code view only if continuity requires it—never use a final-cue fallback.
