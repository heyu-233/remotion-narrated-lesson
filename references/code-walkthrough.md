# Code walkthrough rules

Use static syntax highlighting and declarative code windows. Bind each narration cue to one line, or a very small contiguous range, with transcript-derived timing. Do not use Monaco command scrolling, CSS transitions, or a chapter-wide highlight.

Correct transcript text before writing cues. The transcript is the timing truth; the script is only a semantic reference. Outside a cue, keep the prior code view only if continuity requires it—never use a final-cue fallback.
